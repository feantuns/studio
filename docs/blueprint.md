# **App Name**: Academystream

## Core Features:

- User Authentication: User account creation, login, profile management, and secure password management.
- Course Catalog: Display available courses, allow search and filtering by category, and present course details.
- Secure Purchasing: Purchase and stream course videos.
- Interactive Video Player: Provide an interactive video player, track viewing progress, allow note taking.
- Certificate Issuance: Grant and manage course completion certificates based on completion criteria. Generate download link when the LLM judges that requirements are satisfied. The LLM acts as tool, deciding whether to allow certificate download or not, and providing download link only if appropriate.
- My Courses: Browse the courses currently owned by the user
- My Certificates: Display all available certifications owned by the user.

## Style Guidelines:

- Primary color: Deep, professional blue (#00308F) to convey trust and expertise.
- Background color: Light blue (#E6F0FF) to provide a clean, calm viewing experience.
- Accent color: Rich gold (#D4AF37) to highlight important elements such as calls to action and completion badges.
- Body and headline font: 'Inter', a sans-serif font with a modern, neutral look, suitable for both headlines and body text.
- Use professional and clear icons to represent course categories and features, with gold accents on hover or selection.
- Implement a clean, structured layout that is easy to navigate, emphasizing visual hierarchy for important content.
- Use subtle animations for transitions and feedback to enhance the user experience without being distracting.
